
# 📦 DeliveryNow – Smart Parcel Delivery

A modern parcel delivery scheduling and tracking
application built using Python and Streamlit.

## Features

- Parcel booking
- Custom delivery date and time
- Standard and Express delivery
- Automatic price calculation
- Unique booking ID generation
- Parcel tracking
- Admin dashboard
- SQLite database
- CSV export

## Technology Stack

- Python
- Streamlit
- SQLite
- Pandas
- Custom CSS

## Installation

1. Clone this repository.

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder.

   cd DeliveryNow-Smart-Parcel-Delivery

3. Create a virtual environment.

   python -m venv venv

4. Activate the environment.

   venv\Scripts\activate

5. Install dependencies.

   pip install -r requirements.txt

6. Configure your admin password in:

   .streamlit/secrets.toml

7. Run the application.

   streamlit run app.py
